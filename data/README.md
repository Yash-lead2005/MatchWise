# MatchWise Dataset Documentation

## Dataset
Abt-Buy Entity Resolution Benchmark

## Source
Leipzig Database Group:
https://dbs.uni-leipzig.de/research/projects/benchmark-datasets-for-entity-resolution

## Files
- Abt.csv: Product records from Abt.
- Buy.csv: Product records from Buy.
- abt_buy_perfectMapping.csv: Ground-truth matching pairs.

## Benchmark information
- Abt records: 1,081
- Buy records: 1,092
- Known matches: 1,097

Original files are kept unchanged in data/raw.
Processed outputs and reports are stored separately.
