# MatchWise

Intelligent Product Duplicate Detection
and Resolution Platform.

## Project

MatchWise identifies duplicate product records
across different e-commerce catalogues using
machine learning and human review.

## Technology

- React
- TypeScript
- FastAPI
- Python
- Scikit-learn
- SQLite

## Dataset

Abt-Buy Entity Resolution Benchmark.

Source:
https://dbs.uni-leipzig.de/research/projects/benchmark-datasets-for-entity-resolution
